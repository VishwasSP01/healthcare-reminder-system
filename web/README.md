# Web Dashboard

React + Vite dashboard for the Smart Healthcare Reminder System.

## Run Locally

From this folder:

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

The Vite dev server proxies `/api` requests to the Spring Boot backend at `http://localhost:8080`, so keep the backend running while using the dashboard.

## What The Dashboard Covers

- Patient register/login
- Patient profile summary
- Prescription upload
- Medicine schedule creation
- Reminder list with taken/skipped/snooze actions
- Diet plan view and compliance
- Admin login and patient diet-plan creation
